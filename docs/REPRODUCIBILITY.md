# 运行与复现边界

## 本仓库可复现

从根目录运行 `python -m llmrec.demo` 与 `python -m unittest discover -s tests -v`。无需安装依赖。输入是版本管理中的固定合成 JSON，未使用随机采样。输出覆盖写入 `artifacts/demo.json`，该目录被忽略。

## 真实比赛复现所需材料（尚未提交）

1. 比赛轮次、队伍名称、成绩截图与提交编号，分别证明最好排名和最高分。
2. 基座及 tokenizer 的准确版本／哈希，授权数据来源与快照哈希。
3. 按用户及时间防泄漏的 train/validation 划分；测试集仅作最终评估。
4. 原始代码 commit、环境锁定、GPU 型号、种子、优化器和各阶段完整配置。
5. 清洗审计、自采样 checkpoint、生成配置、筛选与 mask 统计、偏好对来源。
6. SFT→RL→DPO 各阶段 checkpoint、训练日志、故障与回退记录。
7. 官方评分器版本、SID/PID 映射、解码预算、各任务分数及平台回执。

以上缺失时，本仓库只复现教学逻辑，不能承诺得到 1.079 或排名 29。没有下载、训练或测评过实际 OneReason 模型。

## 消融建议

固定验证集、模型版本、种子和推理预算，分别比较基线、清洗／路由、完整轨迹监督、目标 mask、RL、DPO。新增模块可能相互影响，需进行独立与组合实验。记录计算预算与失败实验，避免把多处变更的结果归因于单一方法。

真实数据应保存在被忽略的本地目录；上传前只选择明确授权的文件。`.gitignore` 不能移除已经提交的敏感文件。此仓库未包含密钥、比赛数据或模型权重。
